# Implementation Plan: Slides as JSX

**Branch**: `feat/003-jsx-slides` | **Date**: 2026-11-22 | **Spec**: [spec.md](spec.md)

## Summary

Each slide becomes a numbered `.tsx` file in `src/slides/`, exporting `meta` (kind, section, parent), `copy` (its words by language, title included), and a default component that composes the deck's components freely. A build-time index lists the files in number order and gives the engine the same `Slide[]` it uses today, so stepping, swipe, menu, overview, URL, intro, print, PDF and motion are unchanged. Today's blocks and presets become importable components. Each preset ships as a copyable example slide file in `src/presets/slides/`, and `/gallery` and the showcase render those files. The data block model goes.

## Ponytail pass — removed or deferred

The `ponytail` skill is not installed; minimalism was applied by hand.

- **Removed:**
  - a slide DSL;
  - the registry's data examples (the example files replace them);
  - the `content.ts` block types and `slides.ts` data.
- **Not built:** a visual slide editor, and hot-reload of the index (the build regenerates it).
- **Deferred:** per-slide custom motion (slides keep the engine's motion).

## Project Structure

```text
src/slides/                 # the deck: NN-name.tsx files (meta, copy, default component)
src/slides/index.ts         # generated: imports in number order → Slide[] for the engine
src/components/deck/        # template-owned components: Points, Steps, Facts, Org, Fork, Week, Plan, Lead, Note,
                            #   Chart, Stat, Flow, Timeline, Cycle, OrgChart, Table, Matrix, Quote, Agenda, Compare, Image, ImageGrid
src/presets/slides/         # one copyable example slide file per preset
scripts/slides-index.mjs    # writes src/slides/index.ts; checks numbering and meta
tests/slides/*.spec.ts, tests/tools/slides_test.mjs
```

**Structure Decision**: components live under a template-owned folder (`src/components/deck/`, beside the ported `src/components/ui/`, which is unchanged). Slide files only import components and the `copy` helper.
