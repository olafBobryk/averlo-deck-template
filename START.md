# Start here

Made a repository from this template and want your own deck? Open the Codex or Claude desktop app and open your new repository from GitHub there, signing in with GitHub when it asks: the app copies it to your computer. Then paste the prompt below as your first message and answer the agent's questions. You won't need to type any commands.

```text
I want to make my own slide deck in this repository. I'm not technical, so please do every technical step yourself, and never ask me to type a command: tell me only what to click or open.

Read AGENTS.md and follow its "Making a deck" section. In this order:

1. Set this computer up for the deck: Node, the project's packages and the browser the checks use. If something needs me, such as an installer or a sign-in, tell me in plain words what to click.
2. Start the deck and give me the link to open it.
3. Ask me for my material (notes, documents, an old deck) and talk it through with me, one plain question at a time. Use only my words and figures.
4. Build the slides from the template's preset visuals.
5. Run the deck's checks before you show me anything, and fix anything that fails.
6. Save each change I keep to my repository.
7. When I say the deck is ready, help me put it online with a free Vercel account, and give me the link to share. Later changes go to the same link when I ask.
```
