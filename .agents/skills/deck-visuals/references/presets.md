# Presets

Generated by `npm run presets:doc` (`scripts/presets-doc.mjs`) from the preset registry, `src/presets/registry.ts`, and each preset's example file in `src/presets/slides/`. Do not edit it by hand: change the registry or a file and run the script.

Each preset is a slide file. To use one, copy its file into `src/slides/` with a number (`NN-name.tsx`), put the owner's words and figures in its `copy`, and change its JSX freely. Every word a slide shows comes from `copy`, which has the same words for each language in `src/deck/langs.ts`. The example files carry placeholder words and placeholder numbers only. Every preset is drawn in the gallery at `/gallery`, with its example and a second, different one (`src/presets/slides/alternates/`).

### Bar chart

- Family: `charts`
- Block: `chart`
- Layout: `stack`
- Fits: Categories compared: one or more values for each category.
- File: `src/presets/slides/bar-chart.tsx`


### Image grid

- Family: `images`
- Block: `imageGrid`
- Layout: `stack`
- Fits: Two to six pictures shown together.
- File: `src/presets/slides/image-grid.tsx`

```tsx
// The example of the image grid preset: a headline, a body text and pictures
// shown together. Without a `src` (a path under public/images/), the
// template's placeholder image.
import { Block, Body, Heading, ImageGrid, Lead } from "@/components/deck";
import type { Copy, SlideMeta, SlideProps } from "@/deck/slide";

export const meta: SlideMeta = {
  kind: "slide",
  section: "section",
  layout: "stack",
};

export const copy = {
  en: {
    title: "Image grid",
    section: "Presets",
    headline: "Placeholder text",
    body: "Placeholder text",
    alts: ["Placeholder text", "Placeholder text", "Placeholder text"],
    captions: ["Placeholder text", "Placeholder text", "Placeholder text"],
  },
} satisfies Copy;

export default function ImageGridSlide({ t }: SlideProps<typeof copy>) {
  return (
    <>
      <Heading title={t.title} headline={t.headline} />
      <Body>
        <Block type="lead">
          <Lead>{t.body}</Lead>
        </Block>
        <Block type="imageGrid">
          <ImageGrid
            images={t.alts.map((alt, i) => ({ alt, caption: t.captions[i] }))}
          />
        </Block>
      </Body>
    </>
  );
}
```
